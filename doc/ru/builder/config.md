# Темы и настройки

## Каталог темы {#theme-dir}

Тема представляет собой каталог с файлами, именуемыми по соглашению:

~~~
theme-dir/
  template.html              Шаблон для single-page HTML
  template-multipage.html    Шаблон для multi-page HTML
  template.typ               Шаблон для PDF (Typst)
  style.css                  CSS (встраивается в HTML как {{ style }})
  theme.puml                 Тема PlantUML (вставляется в каждую диаграмму)
  theme.mmd                  Тема Mermaid (вставляется в каждую диаграмму)
  theme.d2                   Тема D2 (вставляется в каждую диаграмму)
  assets/                    Статические файлы, на которые ссылаются шаблоны
~~~

Все файлы являются опциональными: для сборки в конкретном формате достаточно
наличия соответствующего шаблона. Например, для сборки в формате HTML достаточно
`template.html`.

## Тема по умолчанию

Если флаг `-t`/`--theme` не указан, Сборщик использует встроенную тему
`blank`, скомпилированную в исполняемый файл. Тема по умолчанию использует
шрифты ParaType:

- **PT Sans** — основной шрифт HTML и диаграмм
- **PT Serif** — основной шрифт PDF
- **PT Mono** — моноширинный шрифт

Для создания собственной темы рекомендуется экспортировать встроенную тему
командой `init-theme` и отредактировать полученные файлы:

~~~
$ docbake init-theme my-theme
$ ls my-theme/
assets/  style.css  template-multipage.html  template.html
template.typ  theme.d2  theme.mmd  theme.puml
~~~

После этого тему можно использовать при сборке:

~~~
$ docbake -t my-theme build -f page -i doc/ru/index.md -o target/out.html -b doc
~~~

Флаг `-t`/`--theme` разрешается в следующем порядке:

1. Имя встроенной темы (`blank`, `blank`, `digitaltide`)
2. Путь к локальному каталогу темы

Например, команда ниже явно выбирает встроенную тему `digitaltide`:

~~~
$ docbake -t digitaltide build -f page -i doc/ru/index.md -o target/out.html -b doc
~~~

## Базовый каталог {#base-dir}

Флаг `-b`/`--base` задаёт корневой каталог для разрешения абсолютных путей в
директивах `include` и ссылках. Пути, начинающиеся с `/`, разрешаются
относительно базового каталога. Все включаемые файлы и ресурсы должны находиться
внутри базового каталога.

Если флаг не указан, базовым каталогом считается каталог входного файла.

~~~
$ docbake build -f page -i doc/ru/index.md -o out.html -b doc
~~~

В этом примере базовым каталогом является `doc/`, а абсолютный путь
`/assets/image.png` в Markdown-источнике разрешится как `doc/assets/image.png`.

## Шаблоны {#templates}

Шаблоны обрабатываются шаблонизатором [Tera](https://keats.github.io/tera/).
Переменные, доступные шаблону, описаны в разделе [Форматы вывода](formats.md).
Каждый шаблон в теме по умолчанию содержит комментарий с перечнем всех доступных
переменных.

### CSS

Файл `style.css`, если он присутствует в каталоге темы, автоматически читается
Сборщиком и передаётся шаблону в переменной `style`. В шаблоне его содержимое
обычно выводится внутри тега `<style>`:

~~~html
<style>{{ style | safe }}</style>
~~~

### Статические ресурсы

Каталог `assets/` темы копируется в каталог вывода при сборке. Шаблоны могут
ссылаться на эти файлы по относительному пути, например:

~~~html
<img src="{{ asset_prefix }}assets/logo.svg" alt="logo" />
~~~

Переменная `asset_prefix` пуста для single-page HTML и PDF, а для multi-page
HTML содержит относительный путь обратно к корню вывода (например, `../`).

## Темы диаграмм {#diagram-themes}

Файлы `theme.puml`, `theme.mmd` и `theme.d2` применяются к каждой диаграмме
соответствующего типа при сборке. Это позволяет задать единообразные шрифты,
цвета и стили для всех диаграмм в документе.

### PlantUML

Содержимое `theme.puml` вставляется в каждую PlantUML-диаграмму сразу после
строки `@start...`:

~~~
skinparam defaultFontName "PT Sans"
skinparam defaultMonospacedFontName "PT Mono"
~~~

### Mermaid

Содержимое `theme.mmd` вставляется перед источником каждой Mermaid-диаграммы.
Обычно это директива `%%{init: ...}%%`:

~~~
%%{init: {"theme": "base", "themeVariables": {"fontFamily": "PT Sans"}}}%%
~~~

Если диаграмма уже содержит собственную директиву `%%{init:`, тема не
применяется, чтобы избежать конфликтов.

### D2

Содержимое `theme.d2` вставляется перед источником каждой D2-диаграммы. D2
использует собственную систему тем — см. [документацию
D2](https://d2lang.com/tour/themes).

## Кеш артефактов {#cache}

Сборщик кеширует результаты рендеринга диаграмм (PlantUML, Mermaid, D2,
Draw.io), чтобы ускорить повторные сборки. По умолчанию кеш располагается в
стандартном каталоге платформы:

- Linux: `~/.cache/docbake`
- macOS: `~/Library/Caches/docbake`

Кеш можно переопределить флагом `--cache <dir>` или отключить флагом
`--no-cache`.
