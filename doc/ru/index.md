# Назначение

Цель проекта состоит в валидации технической документации, написанной в Markdown
с расширениями проекта, и в генерации артефактов для публикации и
распространения.

Система подготовки документации предназначена для ведения документации на
платформу, её компоненты, а также проекты внедрения.

Документация представляет собой [набор исходных текстов](document.md),
написанных в формате [Markdown](markdown.md) с рядом расширений.

В целевые результаты входят single-page HTML, PDF на базе Typst и объединённый
Markdown. Проект также предусматривает генерацию изображений диаграмм в формате
SVG из исходников PlantUML через вызов внешних инструментов.

Построение и проверка документации выполняются с помощью
[Сборщика](builder/index.md).
