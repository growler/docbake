# Таблицы и списки

## Таблицы

Таблицы используют синтаксис pipe-таблиц. Ячейки разделяются символом `|`,
выравнивание колонок задается символом `':'` в строке разделителя:

~~~markdown
Позиция | Цена
:-------|----:
SRV-001 |  100
SRV-002 |  200
~~~

:::related
# Результат

Позиция | Цена
:------ | ---:
SRV-001 |  100
SRV-002 |  200
:::

### Подпись таблицы

Для того чтобы таблицу можно было адресовать, надо обязательно указать подпись.
Подпись может быть задана в виде отдельного параграфа до или после таблицы,
начинающегося со слова `Table:` (или `table:`). Аналогичные префиксы
используются для блоков кода (`Listing:`) и рисунков (`Figure:`).

~~~markdown
Table: Применяемые стандарты

| RFC      | Описание                |
| -------- | ----------------------- |
| RFC 2822 | Internet Message Format |

...

Стандарты указаны в [таблице](# "Применяемые стандарты")
~~~

:::related
# Результат

Table: Применяемые стандарты

| RFC      | Описание                |
| -------- | ----------------------- |
| RFC 2822 | Internet Message Format |

...

Стандарты указаны в [таблице](# "Применяемые стандарты")
:::

Идентификатор таблицы можно указать явно в следующем формате:

~~~markdown
Table: Применяемые стандарты {#rfc-table}

| RFC      | Описание                |
| -------- | ----------------------- |
| RFC 2822 | Internet Message Format |

...

Стандарты указаны в [таблице](#rfc-table)
~~~

### Многострочные таблицы

Многострочные таблицы позволяют заголовкам и строкам тела занимать несколько
физических строк. Строки тела разделяются пустой строкой. Синтаксис совместим
со стандартом [Pandoc multiline tables].

**Таблица с заголовком.** Сплошная линия из дефисов открывает таблицу. Затем
идут строки заголовка. Линия-разделитель с группами дефисов (разделёнными
пробелами) задаёт ширину и выравнивание столбцов. Тело таблицы завершается ещё
одной сплошной линией:

~~~markdown
-------------------------------------------------------------------
  Выровнен   По         Вправо Влево
  по центру  умолчанию
------------ --------- ------- ------------------------------------
  Первая      строка      12.0 Пример строки, которая
                               занимает несколько физических строк.

  Вторая      строка       5.0 Ещё одна строка. Обратите внимание
                               на пустую строку между строками.
-------------------------------------------------------------------

Table: Пример многострочный таблицы 
~~~

:::related
# Результат

-------------------------------------------------------------------
  Выровнен   По         Вправо Влево
  по центру  умолчанию
------------ --------- ------- ------------------------------------
  Первая      строка      12.0 Пример строки, которая
                               занимает несколько физических строк.

  Вторая      строка       5.0 Ещё одна строка. Обратите внимание
                               на пустую строку между строками.
-------------------------------------------------------------------

Table: Пример многострочный таблицы 
:::

**Таблица без заголовка.** Если таблица начинается с линии-разделителя (а не со
сплошной линии), строки заголовка отсутствуют, и все строки считаются строками
тела. Выравнивание в этом случае определяется по первой строке тела.

~~~markdown
------------ ----------- ------- ------------------------------------
Первая       строка         12.0 Пример многострочной строки без
                                 заголовка.

Вторая       строка          5.0 Ещё одна строка.
------------ ----------- ------- ------------------------------------

Table: Пример таблицы без заголовка 
~~~

:::related
# Результат

------------ ----------- ------- ------------------------------------
Первая       строка         12.0 Пример многострочной строки без
                                 заголовка.

Вторая       строка          5.0 Ещё одна строка.
------------ ----------- ------- ------------------------------------

Table: Пример таблицы без заголовка 
:::

Ширина столбцов в источнике влияет на вывод: если текст в столбце слишком
широкий в PDF или HTML, достаточно расширить группу дефисов в линии-разделителе.

Подпись добавляется в виде параграфа `Table:` до или после таблицы (см.
[«Подпись таблицы»](# "Подпись таблицы")).

[Pandoc multiline tables]: https://pandoc.org/demo/example33/8.9-tables.html

## Списки

Формат позволяет описывать несколько видов списков.

### Ненумерованные списки (bullet lists)

Элемент ненумерованного списка начинается с символа `*`, `+` или `-`:

Если каждый элемент списка начинается с новой строки, то представление списка
будет компактным:

~~~markdown
* Элемент 1
* Элемент 2
* Элемент 3
~~~

:::related
# Результат

* Элемент 1
* Элемент 2
* Элемент 3
:::

Если разделить элементы списка пустой строкой, то получится список, где каждый
элемент представлен отдельным параграфом. В элементах такого списка также можно
использовать другие блочные элементы разметки.

~~~markdown
* Элемент 1

* Элемент 2

  ```
  code
  ```

* Элемент 3
~~~

:::related
# Результат

* Элемент 1

* Элемент 2

  ```
  code
  ```

* Элемент 3
:::

Формат также позволяет описывать вложенные списки:

~~~markdown
* Элемент 1
  + Элемент 1.1
  + Элемент 1.2
* Элемент 2
~~~

:::related
# Результат

* Элемент 1
  + Элемент 1.1
  + Элемент 1.2
* Элемент 2
:::

Разделять элементы списка пустой строкой в этом случае не обязательно.

### Нумерованные списки (ordered lists)

Элемент нумерованного списка начинается с числа, за которым следует точка или
закрывающая скобка. Номер первого элемента определяет начальное значение
нумерации.

~~~markdown
1. Элемент 1
   1. Элемент 1.1
   2. Элемент 1.2
2. Элемент 2
~~~

:::related
# Результат

1. Элемент 1
   1. Элемент 1.1
   2. Элемент 1.2
2. Элемент 2
:::

Нумеровать элементы внутри документа не обязательно, можно всегда использовать
одно число.

~~~markdown
1) Элемент 1
   1) Элемент 1.1
   1) Элемент 1.2
1) Элемент 2
~~~

:::related
# Результат

<!-- The formatter keeps renumbering so leave it be -->

1) Элемент 1
   1) Элемент 1.1
   2) Элемент 1.2
2) Элемент 2
:::

### Списки определений (definition lists)

Списки определений состоят из терминов и их определений. Термин занимает
отдельную строку. Следующая строка с определением начинается с двоеточия `:`;
перед двоеточием допустим отступ до трех пробелов, а после него должен идти хотя
бы один пробел или табуляция.

Термины нужно отделять от предыдущего определения пустой строкой. У одного
термина может быть несколько определений, и наоборот, одно определение может
относиться сразу к нескольким подряд идущим терминам.

Если между термином и определением нет пустой строки, определение записывается в
компактной форме и не выделяется в отдельный абзац. Это удобно для коротких
формулировок.

~~~markdown
Яблоко
:   Плод растений рода Malus.

Апельсин
:   Плод вечнозеленых деревьев рода Citrus.
~~~

:::related
# Результат

Яблоко
:   Плод растений рода Malus.

Апельсин
:   Плод вечнозеленых деревьев рода Citrus.
:::

Определение может занимать несколько строк. Продолжение удобно оформлять с
отступом, но это не обязательно.

~~~markdown
Яблоко
:   Плод растений рода Malus семейства Rosaceae.

Апельсин
:    Плод вечнозеленых деревьев рода Citrus,
который обычно имеет оранжевую кожуру.
~~~

:::related
# Результат

Яблоко
:   Плод растений рода Malus семейства Rosaceae.

Апельсин
:   Плод вечнозеленых деревьев рода Citrus, который обычно имеет оранжевую кожуру и
    округлую форму.
:::

Если перед определением есть пустая строка, его содержимое оформляется как
отдельный абзац. В таком определении можно использовать несколько абзацев и
другие блочные элементы.

~~~markdown
Термин

:   Это определение начинается с отдельного абзаца.

    Это второй абзац того же определения.

    ```
    code example
    ```
~~~

:::related
# Результат

Термин

:   Это определение начинается с отдельного абзаца.

    Это второй абзац того же определения.

    ```
    code example
    ```
:::

У одного термина может быть несколько определений:

~~~markdown
Яблоко
:   Плод растений рода Malus.
:   Название компании Apple в русскоязычных текстах иногда переводят буквально.
~~~

Несколько терминов тоже можно связать с одним определением:

~~~markdown
Термин 1
Термин 2
:   Общее определение.
~~~

### Списки с чекбоксами (task lists)

Элементы списка могут содержать чекбоксы. Для этого после маркера списка
указывается `[ ]` (не отмечено) или `[x]` (отмечено):

~~~markdown
- [x] Задача выполнена
- [ ] Задача не выполнена
- [ ] Ещё одна задача
~~~

:::related
# Результат

- [x] Задача выполнена
- [ ] Задача не выполнена
- [ ] Ещё одна задача
:::
