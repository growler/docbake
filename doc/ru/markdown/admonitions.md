# Специальные блоки (admonitions)

Специальные блоки — это визуально выделенные секции документа, привлекающие
внимание читателя к важной информации. Каждый тип блока имеет свой цвет и
заголовок по умолчанию.

Поддерживаются следующие типы блоков:

| Тип         | Назначение                              |
| ----------- | --------------------------------------- |
| `note`      | Заметка, дополнительная информация      |
| `tip`       | Совет, полезная рекомендация            |
| `warning`   | Предупреждение                          |
| `caution`   | Призыв к осторожности                   |
| `important` | Критически важная информация            |
| `related`   | Связанная информация, нейтральный стиль |

## Базовый синтаксис

Блок задаётся огороженным блоком (fenced div) с именем типа в качестве класса.
Если заголовок внутри блока не указан, используется заголовок по умолчанию,
соответствующий типу блока:

~~~markdown
:::note
Это заметка без пользовательского заголовка.
Заголовок «Note» подставляется автоматически.
:::
~~~

Результат:

:::note
Это заметка без пользовательского заголовка. Заголовок «Note» подставляется
автоматически.
:::

## Блоки с заголовком

Если первый элемент внутри блока — заголовок, он становится заголовком блока
вместо значения по умолчанию:

~~~markdown
:::tip
## Совет дня
Используйте специальные блоки для выделения
важных фрагментов документации.
:::
~~~

Результат:

:::tip
## Совет дня

Используйте специальные блоки для выделения важных фрагментов документации.
:::

## Все типы блоков

:::note
Заметка (note) — дополнительная информация.
:::

:::tip
Совет (tip) — полезная рекомендация.
:::

:::warning
Предупреждение (warning) — обратите внимание.
:::

:::caution
Осторожно (caution) — возможны нежелательные последствия.
:::

:::important
Важно (important) — критически важная информация.
:::

:::related
Связанная информация (related) — нейтральный стиль.
:::

## Идентификаторы и атрибуты

Блоку можно назначить идентификатор и дополнительные атрибуты, используя
стандартный синтаксис атрибутов:

~~~markdown
:::{.warning #предупреждение-о-совместимости}
## Совместимость
Функция доступна начиная с версии 2.0.
:::

Подробности описаны в [предупреждении](#предупреждение-о-совместимости).
~~~

Результат:

:::{.warning #предупреждение-о-совместимости}
## Совместимость

Функция доступна начиная с версии 2.0.
:::

Подробности описаны в [предупреждении](#предупреждение-о-совместимости).

Admonition-блоки являются fenced div, поэтому к ним также применимы условные
атрибуты `if-format` и `if-variant`:

~~~markdown
:::{.warning if-format="pdf" if-variant="enterprise"}
## Только для PDF/Enterprise
Этот warning виден только в соответствующем профиле.
:::
~~~

## Вложенное содержимое

Внутри блоков допускается любая разметка: форматирование текста, списки, блоки
кода, таблицы:

~~~markdown
:::note
## Пример с разным содержимым

Текст с **жирным**, *курсивом* и `кодом`.

- Первый пункт
- Второй пункт

```python
def hello():
    print("Hello!")
```

| Колонка A | Колонка B |
|-----------|-----------|
| Один      | Два       |
:::
~~~
