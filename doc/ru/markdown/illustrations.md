# Иллюстрации

Для вставки изображений используется следующий синтаксис:

~~~markdown
![Описание](путь/к/изображению "Подсказка"){#id .class attr=value}
~~~

Если идентификатор не указан, то он создается автоматически из заголовка, или,
если заголовок отсутствует, из описания.

Классы транслируются в HTML без изменений.

Если изображение отделено от текста пустой строкой до и после, то оно выводится
как отдельная иллюстрация с собственной подписью и идентификатором. В противном
случае, оно вставляется в текст.

Поддерживаются форматы PNG, JPEG и SVG.

Файл изображения будет скопирован в целевой каталог при сборке, если это
требуется форматом. В частности, для формата HTML все файлы будут скопированы в
подкаталог `static`, а ссылки внутри результирующих HTML документов будут
переписаны соответственно.

## Встроенные изображения {.inline-image}

Если изображение находится внутри абзаца вместе с текстом (т.е. не является
единственным содержимым абзаца), ему автоматически присваивается CSS-класс
`.inline-image`. Этот класс задает размер изображения, соответствующий высоте
строки текста, и корректное вертикальное выравнивание.

~~~markdown
Иллюстрация ![Кот](../assets/cat.svg) непосредственно в тексте.
~~~

Иллюстрация ![Кот](../../assets/cat.svg) непосредственно в тексте.

Класс `.inline-image` добавляется автоматически — указывать его вручную не
требуется.

## Атрибуты изображений

Атрибуты указываются в фигурных скобках после ссылки на изображение:

~~~markdown
![Описание](путь/к/изображению){#id width=50%}
~~~

### `width`

Атрибут `width` задаёт ширину изображения. Значение указывается в процентах или
в абсолютных единицах:

~~~markdown
![Иллюстрация, 50%](../assets/illustration.png){width=50%}
~~~

![Иллюстрация, 50%](../../assets/illustration.png){width="50%"}

~~~markdown
![Иллюстрация, SVG](../assets/cat.svg){#cat width=25%}
~~~

![Иллюстрация, SVG](../../assets/cat.svg){#cat width="25%"}

Код `[ссылка на иллюстрацию](#cat)` сделает работающую [ссылку на
иллюстрацию](#cat).

### `height`

Атрибут `height` задаёт высоту изображения:

~~~markdown
![Иллюстрация](../assets/illustration.png){height=3cm}
~~~

### Единицы измерения

Каждый формат принимает свои единицы измерения:

HTML

:   Значение записывается в элемент `<img>` без изменений. CSS темы задаёт
    `max-width: 100%; height: auto`, поэтому размер изображения задаёт ширина, а
    высота сохраняет пропорции.

PDF

:   Typst принимает `%`, `cm`, `mm`, `in`, `pt` и `em`. Единицу `px` и число без
    единицы Typst не принимает.

DOCX

:   Принимаются `%`, `cm`, `mm`, `in`, `pt`, `em`, `px` и число без единицы (пиксели
    при 96 DPI). `em` -- размер шрифта основного текста. Ширина в `%` -- часть
    доступной ширины. Доступная ширина описана в разделе [Размер изображения в
    DOCX](# "Размер изображения в DOCX"). Высота в `%` -- часть высоты текста на
    странице. Значение `auto` равно отсутствию атрибута. Сборка останавливается с
    ошибкой, если значение неправильное.

Только `%` работает во всех форматах. Для изображения, которое должно быть во
всех форматах, задавайте `width` в `%`.

### Размер изображения в DOCX

Если задан только `width` или только `height`, то изображение сохраняет
пропорции. Если заданы оба атрибута, то изображение получает оба значения.

Изображение без атрибутов получает свой размер в пикселях при 96 DPI.
Изображение в тексте без атрибутов получает высоту, равную размеру шрифта стиля
`Normal` (`1em`).

Доступная ширина зависит от абзаца, в котором находится изображение:

- В абзаце пункта списка -- ширина текста на странице без отступа уровня списка.
- В ячейке таблицы -- ширина ячейки без левого и правого полей ячейки. Ширина
  объединённой ячейки -- сумма ширин её столбцов.
- В других абзацах -- ширина текста на странице без левого отступа стиля абзаца.
  Если стиль не задаёт отступ, то используется отступ базового стиля (`based_on`).

Стиль абзаца с изображением:

- `ImageBlock` -- изображение без текста и диаграмма.
- `Normal` -- изображение в тексте.
- `Quote` -- изображение в цитате.
- `DefinitionBody` -- изображение в определении.
- Стиль тела предупреждения -- изображение в предупреждении.
- `Heading1`--`Heading6`, `DefinitionTerm`, `Caption` -- изображение в заголовке,
  в термине и в подписи.

Стиль абзаца не зависит от блока вокруг абзаца. Например, изображение в
предупреждении внутри цитаты получает ширину стиля тела предупреждения, а не
ширину стиля `Quote`.

Диаграмма и изображение с подписью в пункте списка не получают отступ списка.
Для них доступная ширина -- ширина текста на странице без отступа стиля
`ImageBlock`.

Если изображение шире доступной ширины или выше области текста на странице, то
изображение уменьшается. Ширина и высота уменьшаются в одинаковое число раз.
Если заданы оба атрибута, то изображение сохраняет отношение двух заданных
значений.

## Подписи к изображениям

Для добавления подписи используется строка с префиксом `Figure:` (или
`figure:`), размещённая перед изображением:

~~~markdown
Figure: Подпись к изображению {#label}

![Описание](../assets/illustration.png){width=50%}
~~~

Figure: Подпись к изображению {#illustration-caption}

![Описание](../../assets/illustration.png){width="50%"}

В фигурных скобках после текста подписи можно указать идентификатор для ссылки
на иллюстрацию.

## Изображение без атрибутов

Размер изображения без атрибутов зависит от формата:

HTML

:   Собственный размер изображения, но не больше ширины колонки текста. CSS темы
    задаёт `max-width: 100%`.

PDF

:   Собственный размер изображения: пиксели при разрешении из файла, или при 72
    DPI, если файл не задаёт разрешение. Если изображение не помещается в область
    текста, то оно уменьшается и сохраняет пропорции.

DOCX

:   Пиксели при 96 DPI. Если изображение шире доступной ширины или выше области
    текста, то оно уменьшается и сохраняет пропорции. Доступная ширина описана в
    разделе [Размер изображения в DOCX](# "Размер изображения в DOCX").

![Иллюстрация](../assets/illustration.png)
~~~
