# Иллюстрации

Для вставки изображений используется следующий синтаксис:

~~~markdown
![Описание](путь/к/изображению "Подсказка"){#id .class attr=value}
~~~

Если идентификатор не указан, то он создается автоматически из заголовка, или,
если заголовок отсутствует, из описания.

Классы транслируются в HTML без изменений.

Если изображение отделено от текста пустой строкой до и после, то оно выводится
как отдельная иллюстрация с собственной подписью и идентификатором. В противном
случае, оно вставляется в текст.

Поддерживаются форматы PNG, JPEG и SVG.

Файл изображения будет скопирован в целевой каталог при сборке, если это
требуется форматом. В частности, для формата HTML все файлы будут скопированы в
подкаталог `static`, а ссылки внутри результирующих HTML документов будут
переписаны соответственно.

## Встроенные изображения {.inline-image}

Если изображение находится внутри абзаца вместе с текстом (т.е. не является
единственным содержимым абзаца), ему автоматически присваивается CSS-класс
`.inline-image`. Этот класс задает размер изображения, соответствующий высоте
строки текста, и корректное вертикальное выравнивание.

~~~markdown
Иллюстрация ![Кот](../assets/cat.svg) непосредственно в тексте.
~~~

Иллюстрация ![Кот](../../assets/cat.svg) непосредственно в тексте.

Класс `.inline-image` добавляется автоматически — указывать его вручную не
требуется.

## Аттрибуты изображений

Аттрибуты указываются в фигурных скобках после ссылки на изображение:

~~~markdown
![Описание](путь/к/изображению){#id width=50%}
~~~

### `width`

Аттрибут `width` задаёт ширину изображения. Значение указывается в процентах или
в абсолютных единицах:

~~~markdown
![Иллюстрация, 50%](../assets/illustration.png){width=50%}
~~~

![Иллюстрация, 50%](../../assets/illustration.png){width="50%"}

~~~markdown
![Иллюстрация, SVG](../assets/cat.svg){#cat width=25%}
~~~

![Иллюстрация, SVG](../../assets/cat.svg){#cat width="25%"}

Код `[ссылка на иллюстрацию](#cat)` сделает работающую [ссылку на
иллюстрацию](#cat).

## Подписи к изображениям

Для добавления подписи используется строка с префиксом `Figure:` (или
`figure:`), размещённая перед изображением:

~~~markdown
Figure: Подпись к изображению {#label}

![Описание](../assets/illustration.png){width=50%}
~~~

Figure: Подпись к изображению {#illustration-caption}

![Описание](../../assets/illustration.png){width="50%"}

В фигурных скобках после текста подписи можно указать идентификатор для ссылки
на иллюстрацию.

## Изображение без аттрибутов

Изображение без аттрибутов отображается на всю ширину страницы:

~~~markdown
![Иллюстрация](../assets/illustration.png)
~~~

![Иллюстрация](../../assets/illustration.png)
