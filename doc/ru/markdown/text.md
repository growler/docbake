# Текстовая разметка

## Инлайн-разметка

Внутри текста можно использовать следующие элементы разметки:

table: Синтаксис инлайн-разметки {#inline-markup}

**Синтаксис**           | **Результат**
----------------------- | -----------------
`*курсив*`              | *курсив*
`_курсив_`              | _курсив_
`**жирный**`            | **жирный**
`__жирный__`            | __жирный__
`~~зачеркнутый~~`       | ~~зачеркнутый~~
`` `неформатируемый` `` | `неформатируемый`
`\*экранирование\*`     | \*экранирование\*

## Экранирование (backslash escapes)

Любой символ пунктуации ASCII можно экранировать обратной косой чертой, чтобы он
был выведен буквально и не интерпретировался как разметка:

~~~markdown
\*не курсив\*  
\# не заголовок  
\[не ссылка\]  
~~~

:::related
# Результат

\*не курсив\*\
\# не заголовок\
\[не ссылка\]
:::

Экранирование работает для следующих символов:

`` \ ` * _ { } [ ] ( ) # + - . ! | ~ ``

Внутри блоков кода (как инлайновых, так и огороженных) экранирование не
действует — все символы выводятся буквально.

## Параграфы и переносы строк

Параграфы отделяются друг от друга пустой строкой. Обычные переносы строки
внутри параграфа трактуются как пробел (soft line break).

Для принудительного переноса строки внутри параграфа (hard line break)
необходимо поставить два или более пробела в конце строки, либо обратную косую
черту `\` перед переносом:

~~~markdown
Первая строка ␣ ␣  
Вторая строка (перенос через два пробела)

Первая строка\
Вторая строка (перенос через обратную косую черту)
~~~

:::related
# Результат

Первая строка  
Вторая строка (перенос через два пробела)

Первая строка\
Вторая строка (перенос через обратную косую черту)
:::

## Заголовки

Заголовки начинаются с одного или нескольких символов `#`. Количество символов
определяет уровень заголовка, максимальный уровень - 6.

Внутри заголовков допускается, но не рекомендуется использовать
[inline-разметку](#inline-markup).

Перед заголовком и после него должна быть пустая строка.

Идентификатор заголовка создается автоматически из его текста, или может быть
задан явно в следующем формате:

~~~markdown
# Заголовок {#header-id}
~~~

Заголовки автоматически включаются в таблицу содержания документа. Можно
исключить конкретный заголовок из таблицы содержания, указав для него атрибут
`{.unlisted}`:

~~~markdown
# Заголовок {.unlisted}
~~~

Также можно исключить заголовок из нумерации, указав для него атрибут
`{.unnumbered}`:

~~~markdown
# Заголовок {.unnumbered}
~~~

## Блоки кода (code blocks) {#блоки-кода}

### Огороженные блоки кода (fenced code blocks)

Блок кода ограничивается строками из трех или более обратных кавычек (```` ```
````) или тильд (`~~~`). После открывающего ограничителя можно указать язык для
подсветки синтаксиса:

~~~markdown
```rust
fn main() {
    println!("Hello, world!");
}
```
~~~

:::related
# Результат

```rust
fn main() {
    println!("Hello, world!");
}
```
:::

Если внутри блока кода необходимо использовать тройные обратные кавычки,
закрывающий ограничитель должен содержать большее количество символов, чем
содержимое:

`````markdown
````markdown
```rust
код...
```
````
`````

### Расширенная строка информации {#расширенная-строка-информации}

После указания языка в строке информации можно добавить описательный текст. Этот
текст используется для автоматического создания идентификатора блока кода, по
тем же правилам, что и [идентификаторы заголовков](#заголовки): текст приводится
к нижнему регистру, пробелы заменяются на дефисы, специальные символы удаляются.

~~~markdown Пример ссылки на блок кода
```rust Базовая функция
fn basic() {}
```
~~~

Этот [блок кода](#пример-ссылки-на-блок-кода) получит идентификатор
`базовая-функция` и будет доступен для [ссылок](links.md#метки):

~~~markdown
См. [пример базовой функции](#базовая-функция).
~~~

Если два или более блока кода имеют одинаковый описательный текст, к
идентификатору автоматически добавляется суффикс (`-1`, `-2`, и т.д.) для
уникальности — так же, как для заголовков. Идентификаторы блоков кода и
заголовков разделяют общее пространство имен: блок кода не может случайно
получить тот же идентификатор, что и заголовок.

### Атрибуты блоков кода {#атрибуты-блоков-кода}

Блоки кода поддерживают атрибуты в формате `{#id .class key=val}`, аналогично
[заголовкам](#заголовки) и другим элементам. Атрибуты указываются после языка (и
описательного текста, если он есть):

~~~markdown
```rust {#my-example data-line="5"}
fn main() {}
```
~~~

В HTML выводе атрибуты будут установлены на элементе `<pre>`:

```html
<pre id="my-example" data-line="5" style="...">
  <code class="language-rust">...</code>
</pre>
```

Явно заданный идентификатор `{#id}` имеет приоритет над автоматическим.
Описательный текст и атрибуты можно комбинировать:

~~~markdown
```python HTTP-клиент {.important data-version="2"}
import requests
```
~~~

Здесь идентификатор будет автоматически создан из описания — `http-клиент`, а
атрибуты `.important` и `data-version` будут добавлены к элементу.

Если указан и описательный текст, и явный идентификатор, используется явный
идентификатор:

~~~markdown
```rust Базовая функция {#basic-fn .example}
fn basic() {}
```
~~~

Идентификатор будет `basic-fn`, а не автоматически созданный из описания.

Специальный класс `.as-code` подавляет преобразование блока кода в диаграмму для
языков диаграмм (`mermaid`, `plantuml`, `typst`, `d2`). Подробнее см. раздел
[Отображение кода диаграммы](diagrams.md#отображение-кода-диаграммы).

Аттрибут `start` включает нумерацию строк кода:

~~~~markdown
~~~rust {start=1}
fn main() {
    println!("Hello, world!");
}
~~~
~~~~

:::related
## Результат

~~~rust {start=1}
fn main() {
    println!("Hello, world!");
}
~~~
:::

### Подпись блока кода {#подпись-блока-кода}

Блоку кода можно задать подпись (caption), аналогично [подписям
таблиц](tables-lists.md#подпись-таблицы) и [подписям диаграмм](diagrams.md). Для
этого перед блоком кода размещается отдельный параграф с префиксом `Listing:`
(или `listing:`).

~~~markdown
Listing: Пример функции main {#listing-main}

```rust
fn main() {
    println!("Hello, world!");
}
```
~~~

:::related
# Результат

Listing: Пример функции main {#listing-main}

```rust
fn main() {
    println!("Hello, world!");
}
```
:::

Подпись отображается **над** блоком кода как в HTML, так и в PDF выводе.

В PDF (Typst) листинги нумеруются отдельно от таблиц и рисунков с префиксом
«Листинг» (или «Listing» для английского языка документа).

Идентификатор для ссылки можно указать в фигурных скобках после текста подписи —
`{#id}`. Если идентификатор не указан, он создаётся автоматически из текста
подписи по тем же правилам, что и [идентификаторы заголовков](#заголовки).
Ссылка на листинг выше: `[листинг](#listing-main)` — [листинг](#listing-main).

### Inline-код (code spans)

Для inline-кода используются обратные кавычки. Если внутри кода нужна обратная
кавычка, используйте двойные обратные кавычки:

~~~markdown
Вызовите функцию `main()`.
Литерал `` `обратная кавычка` `` внутри кода.
~~~

:::related
# Результат

Вызовите функцию `main()`.\
Литерал `` `обратная кавычка` `` внутри кода.
:::

### Блоки кода с отступом (indented code blocks)

Строки, начинающиеся с четырех или более пробелов, также образуют блок кода.
Рекомендуется использовать огороженные блоки кода вместо блоков с отступом,
поскольку огороженные блоки поддерживают подсветку синтаксиса и более явно
обозначают границы кода.

~~~markdown
Пример вывода

␣ ␣ ␣ ␣ $ echo ok
␣ ␣ ␣ ␣ ok

Продолжение текста
~~~

:::related
# Результат

Пример вывода

    $ echo ok
    ok

Продолжение текста
:::

## Цитаты (block quotes) {#цитаты}

Цитаты начинаются с символа `>`. Цитаты могут содержать любые блочные элементы и
быть вложенными:

~~~markdown
> Это цитата.
>
> > Вложенная цитата.
>
> Продолжение цитаты.
~~~

:::related
# Результат

> Это цитата.
>
> > Вложенная цитата.
>
> Продолжение цитаты.
:::

Внутри цитат можно использовать списки, блоки кода и другие элементы разметки:

~~~markdown
> Пример с кодом:
>
> ```
> код внутри цитаты
> ```
>
> - элемент списка
~~~

:::related
# Результат

> Пример с кодом:
>
> ```
> код внутри цитаты
> ```
>
> - элемент списка
:::

## Горизонтальный разделитель (thematic break)

Горизонтальный разделитель создается строкой из трех или более символов `-`, `*`
или `_`:

~~~markdown
Текст до разделителя.

---

Текст после разделителя.
~~~

:::related
# Результат

Текст до разделителя.

---

Текст после разделителя.
:::

## Inline HTML

В тексте можно использовать HTML-разметку. В HTML выводе она будет передана без
изменений:

~~~markdown
Текст с <abbr title="Hyper Text Markup Language">HTML</abbr> тегом.

<div style="color: red">
Блок HTML.
</div>
~~~

::: important
## Внимание

Inline и блочный HTML передаётся в HTML вывод без изменений, но **игнорируется**
при генерации PDF. Не рекомендуется полагаться на HTML-разметку, если документ
предназначен для вывода в PDF.
:::
